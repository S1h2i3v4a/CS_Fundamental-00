1. 3-Way Handshake Sequence Breakdown

StepSender -> ReceiverActive FlagsSeq / Ack EquationsState Transition
1Client -> ServerSYN = 1Seq = ISN_c (consumes 1 seq)Client: CLOSED -> SYN-SENT
2Server -> ClientSYN = 1, ACK = 1Seq = ISN_s, Ack = ISN_c + 1Server: LISTEN -> SYN-RCVD
3Client -> ServerACK = 1Seq = ISN_c + 1, Ack = ISN_s + 1Both enter ESTABLISHED state

2. SYN Cookies Defense Principle

Zero State Allocation: Server does not allocate memory on SYN arrival.
ISN_s = HMAC(Client_IP, Client_Port, Server_IP, Server_Port, Counter, Key)
State is instantiated only upon reception of verified final ACK!
