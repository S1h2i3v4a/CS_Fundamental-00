CIDR & Supernetting

Classless Inter-Domain Routing (CIDR), 3 Mandatory Block Allocation Rules, Supernetting Mechanics, and Longest Prefix Match (LPM) Routing Forwarding Algorithm.

1. 3 Mandatory Rules of CIDR Allocation

Rule 1: Addresses in a block must be contiguous.
Rule 2: Total count of addresses must be power of 2 (N = 2^(32 - n)).
Rule 3: First address (in decimal integer) must be divisible by block size N.

3. Longest Prefix Match (LPM)

When multiple routing prefixes match an incoming destination IP address, the router selects the entry with the highest prefix length (most specific mask).
