2. Closed-Loop Feedback Mechanisms

1. Choke Packets: Router generates direct ICMP warning message to sending host.
2. Hop-by-Hop Backpressure: Immediate upstream link throttling.
3. Explicit Congestion Notification (ECN): Marks IP header bits without packet dropping.
