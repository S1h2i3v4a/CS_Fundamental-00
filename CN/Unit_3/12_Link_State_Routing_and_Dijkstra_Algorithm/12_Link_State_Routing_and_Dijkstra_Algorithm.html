1. 5 Phases of Link State Routing

1. Discover neighbors via periodic HELLO packets.
2. Measure link cost/latency via ECHO test.
3. Construct Link State Packet (LSP) with Seq Number & Age.
4. Reliable Flooding of LSP to all routers in Autonomous System.
5. Execute Dijkstra's Algorithm independently on Link State Database (LSDB).
