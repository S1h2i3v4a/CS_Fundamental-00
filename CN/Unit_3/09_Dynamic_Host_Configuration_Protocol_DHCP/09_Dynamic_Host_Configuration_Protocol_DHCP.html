1. The 4-Step DORA Protocol Summary

StepMessage NameDirectionL3 / L4 AddressingAction
DDHCP DiscoverClient -> ServerSrc 0.0.0.0:68 -> Dst 255.255.255.255:67Broadcast to find any DHCP server
ODHCP OfferServer -> ClientSrc Server_IP:67 -> Dst Client/Broadcast:68Offers candidate IP, mask, lease duration
RDHCP RequestClient -> ServerSrc 0.0.0.0:68 -> Dst 255.255.255.255:67Broadcast accepting one server's offer
ADHCP ACKServer -> ClientSrc Server_IP:67 -> Dst Client/Broadcast:68Finalizes lease with gateway and DNS info
