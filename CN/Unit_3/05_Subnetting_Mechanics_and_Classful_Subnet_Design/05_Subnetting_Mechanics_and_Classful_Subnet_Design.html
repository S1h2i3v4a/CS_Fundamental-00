1. Fundamental Formulas

Subnet Engineering Rules

Number of Subnets = 2^s (where s = borrowed bits)
Valid Hosts per Subnet = 2^h - 2 (where h = remaining host bits)
Block Size (Jump Size) = 256 - Mask Octet Value = 2^h
Subnet ID = Destination IP Bitwise AND Subnet Mask
