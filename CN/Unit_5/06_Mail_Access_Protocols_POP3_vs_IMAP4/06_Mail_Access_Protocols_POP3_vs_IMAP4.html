1. Message Access Paradigm (PULL vs PUSH)

While SMTP handles inter-server PUSH operations, client devices require PULL protocols (POP3 or IMAP4) to retrieve messages from intermediate mailbox buffers.

Architectural Divergence
POP3 views the mail server as a temporary post office drop box; IMAP4 views the server as a perpetual, synchronized cloud database.

2. POP3 Operational Modes

  • Delete Mode: Mail is transferred to client hard drive and immediately purged from server spool.
  • Keep Mode: Messages persist on the server following retrieval, but message state changes remain strictly local.
