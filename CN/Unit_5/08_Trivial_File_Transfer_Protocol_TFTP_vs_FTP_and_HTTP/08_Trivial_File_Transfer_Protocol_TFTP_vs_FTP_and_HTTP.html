1. Trivial FTP Architecture & Minimalist Design

TFTP is an ultra-lightweight, UDP-based file transfer protocol engineered to fit into low-memory bootstrap ROMs and BIOS chips.

The Stop-and-Wait Transfer Engine
Operating over UDP Port 69, TFTP divides data into fixed 512-byte blocks. Each transmitted block demands explicit acknowledgment before the succeeding block can be released. A block < 512 bytes signals End of File (EOF).
