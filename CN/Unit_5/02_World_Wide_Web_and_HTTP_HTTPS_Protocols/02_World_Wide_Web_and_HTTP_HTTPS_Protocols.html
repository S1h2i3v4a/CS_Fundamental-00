1. HTTP Fundamentals & Stateless Architecture

Hypertext Transfer Protocol is the foundation of data communication for the World Wide Web, operating as a request-response protocol over TCP.

Stateless Character of HTTP
HTTP does not preserve client conversational state between successive requests. To maintain stateful interactions (shopping carts, user logins), modern web architectures use HTTP Cookies and JWT Tokens.
