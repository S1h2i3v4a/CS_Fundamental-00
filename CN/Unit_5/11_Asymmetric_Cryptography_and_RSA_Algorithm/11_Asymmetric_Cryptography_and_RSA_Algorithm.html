1. Asymmetric Public-Key Cryptography

Asymmetric cryptography eliminates key exchange vulnerability by deploying dual mathematically coupled keys: a universally published Public Key and a confidential Private Key.

The Fundamental RSA Mathematical Engine
Security rests upon the computational difficulty of factoring the product n = p × q of two massive prime integers.

2. RSA Key Selection Sequence

  1. Select distinct large primes p and q.
  2. Calculate modulus: n = p × q.
  3. Compute totient: φ(n) = (p - 1)(q - 1).
  4. Choose public exponent e such that gcd(e, φ(n)) = 1.
  5. Compute private exponent d ≡ e-1 (mod φ(n)).
Encryption: C = Pe mod n | Decryption: P = Cd mod n (P < n)
