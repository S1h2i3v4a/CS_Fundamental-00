1. Remote Login Paradigm

Remote login allows a terminal user on a local system to log in to and execute commands on a remote timesharing system across an IP internetwork.

The Role of Network Virtual Terminal (NVT)
To overcome terminal and keyboard heterogeneity across operating systems, TELNET maps local terminal characteristics to a universal intermediate representation called NVT.
