## 📌 Document Overview

This module provides a **strictly verified 3-page summary PDF** engineered for ultra-fast last-minute exam revision, formula lookups, and conceptual recaps of Unit 5.

- **Page 1: Foundations, Addressing & Web Protocols**
  - DNS Architecture, 3 Divisions of Domain Space, Recursive vs Iterative resolution, Resource Records (A, AAAA, CNAME, MX, NS, PTR).
  - World Wide Web, HTTP Request-Response format, Methods, Status codes, Persistent vs Non-Persistent HTTP, HTTP vs HTTPS.
  - Remote Login & TELNET (RFC 854), NVT 7-bit character set + 8-bit IAC commands, Operating modes, TELNET vs SSH security.
  - Electronic Mail (E-Mail) Architecture: 4 Scenarios, User Agent (UA), Message Transfer Agent (MTA), Message Access Agent (MAA), MIME headers.

- **Page 2: Email Protocols, File Transfers & Network Management**
  - Simple Mail Transfer Protocol (SMTP RFC 821/2821), Push protocol, TCP Port 25/587, 3 Phases (HELO, MAIL FROM, RCPT TO, DATA, QUIT), Mail relays, MX lookup, Email Gateways.
  - Mail Access Protocols: POP3 (Port 110/995, Delete vs Keep mode) vs IMAP4 (Port 143/993, central sync, folders, partial fetch).
  - File Transfer Protocol (FTP RFC 959): Dual connections (Control Port 21 vs Data Port 20), Active Mode (PORT) vs Passive Mode (PASV), Anonymous FTP.
  - Trivial File Transfer Protocol (TFTP RFC 1350): UDP Port 69, 512-byte blocks, Stop-and-Wait ACK, EOF detection, Master 3-way comparison (FTP vs TFTP vs HTTP).

- **Page 3: Network Management, Cryptography, Compression & Commands**
  - SNMP Framework: Manager & Agent, UDP Port 161 polling vs UDP Port 162 Trap, Management Triad (SMI syntax, MIB tree `1.3.6.1.2.1`, SNMP PDUs).
  - Cryptography Foundations: 4 Pillars (Confidentiality, Integrity, Authentication, Non-repudiation), Symmetric Ciphers (Caesar, DES 64-bit/56-bit vs AES 128-bit/SPN).
  - Asymmetric Cryptography & RSA Algorithm: Key generation steps ($p, q, n, \phi(n), e, d$), Encryption $C = P^e \bmod n$, Decryption $P = C^d \bmod n$, Solved character "F" numerical ($p=3, q=11, n=33, e=3, d=7, P=5 \implies C=26$).
  - Data Compression: Lossless (RLE, Huffman, LZW) vs Lossy (Audio psychoacoustics, Frequency & Temporal masking hammer strike analogy).
  - Firewalls (Packet filtering, Stateful, Application proxy) & 5 Diagnostic Commands (`ipconfig`, `nslookup`, `tracert`, `ping`, `netstat`).
