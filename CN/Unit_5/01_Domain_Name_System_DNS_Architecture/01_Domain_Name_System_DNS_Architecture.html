1. Domain Name System (DNS) Overview

DNS translates human-readable hostnames into machine-routable IP addresses using a distributed, hierarchical database.

Protocol Standards & Port Assignment
Transport Protocol: UDP Port 53 for standard interactive queries (≤ 512 bytes). TCP Port 53 for zone transfers and extended EDNS0 responses (> 512 bytes).

4. Core Resource Record (RR) Types

Format: <Domain_Name, Value, Type, TTL>
  • A Record: Resolves hostname to 32-bit IPv4 address.
  • AAAA Record: Resolves hostname to 128-bit IPv6 address.
  • CNAME Record: Canonical alias pointing alias domain to master domain.
  • MX Record: Identifies primary and backup mail exchange routing servers.
  • NS Record: Delegates DNS zone authority to specified nameservers.
