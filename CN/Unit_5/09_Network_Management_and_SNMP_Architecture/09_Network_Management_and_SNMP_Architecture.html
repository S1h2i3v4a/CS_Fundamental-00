1. SNMP Operational Architecture

Simple Network Management Protocol defines a framework for managing heterogenous devices in an internetwork across a manager-agent architecture.

Transport Layer Port Allocation
UDP Port 161: Managed Agent port accepting polling queries (GetRequest, SetRequest).
UDP Port 162: Manager NMS station port listening for unsolicited asynchronous alarms (Traps).

3. The Three Primary Management Functions

  • Status Polling (GetRequest / GetNextRequest): Periodic inspection of interface traffic and CPU load.
  • Remote Configuration (SetRequest): Modifying routing parameters and port operational states.
  • Event Notification (Trap): Unsolicited emergency alarm reporting critical hardware failures.
