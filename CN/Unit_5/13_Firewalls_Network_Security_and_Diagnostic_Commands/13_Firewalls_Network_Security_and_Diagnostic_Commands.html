1. Firewall Defensive Taxonomy

A firewall secures network perimeters by analyzing inbound and outbound packet flows against institutional access policies.

Three Architectural Tiers
1. Stateless Packet Filters: Fast, rule-based matching on L3/L4 headers.
2. Stateful Inspection: Dynamically tracks TCP handshake states to prevent unauthorized external ingress.
3. Application Gateways: Terminates connections and validates application payloads at Layer 7.
