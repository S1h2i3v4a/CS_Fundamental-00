1. FTP Dual-Connection Architecture

File Transfer Protocol establishes two discrete logical connections over TCP: an interactive Control Connection and an ephemeral Data Connection.

Functional Connection Roles
Control Connection (Port 21): Stays persistently open throughout session; transmits 7-bit ASCII commands and 3-digit replies.
Data Connection (Port 20 / PASV): Opens dynamically per file transfer / directory listing; closes automatically upon completion.

3. Key FTP Commands

  • USER / PASS: Client authentication credentials.
  • PORT / PASV: Selects active vs passive data connection negotiation mode.
  • RETR / STOR: Retrieves file from server / stores local file to server.
  • QUIT: Gracefully closes control connection.
