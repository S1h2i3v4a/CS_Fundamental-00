1. Address Classification & Key Properties

Address Type Bit Size Hardware / OS Location Delivery Horizon
Physical (MAC) 48 bits (6 Bytes) NIC ROM / Firmware Node-to-Node (Local subnet only)
Logical (IPv4) 32 bits (4 Bytes) OS TCP/IP Stack Configuration Host-to-Host (Global internetwork)
Logical (IPv6) 128 bits (16 Bytes) OS TCP/IP Stack Configuration Host-to-Host (Next-gen Internet)
Port Number 16 bits (0 - 65535) Kernel Socket Table Process-to-Process (Application binding)
URL / FQDN Variable ASCII Application layer / Browser cache User interface (DNS resolved)

2. The Socket Abstraction

Network communication me process-to-process connection hamesha do Sockets ke beech banta hai:

Source Socket:      192.168.1.15 : 54321  (Client Ephemeral Port)
Destination Socket: 142.250.190.46 : 443  (Google Web Server HTTPS Port)
Golden Rule: Source & Destination IP addresses never change as packet moves from router to router. But Source & Destination MAC addresses change at EVERY hop!
