2. Network Layer vs Transport Layer Delivery (Exam Favorite)

  • Network Layer: Sirf packet ko Source Host computer se Destination Host computer tak pahunchata hai (Host-to-Host delivery). Isse yeh nahi pata hota ki destination computer par kaunsa application software packet ka intezar kar raha hai.
  • Transport Layer: Packet ke andar ke Port Number ko inspect karke data ko destination computer ke exact running software process (e.g., Chrome tab vs Spotify) tak pahunchata hai (Process-to-Process delivery).
