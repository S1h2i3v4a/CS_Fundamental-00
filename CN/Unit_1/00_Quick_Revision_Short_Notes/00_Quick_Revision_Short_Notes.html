1. 5 Core Components of Data Communication
  • 1. Message: Actual data payload to communicate (Text, Number, Audio, Video).
  • 2. Sender: Workstation/phone generating the source bit stream.
  • 3. Receiver: Sink device accepting the delivered information.
  • 4. Transmission Medium: Guided (Twisted pair, Coax, Fiber) or Unguided (RF).
  • 5. Protocol: Agreed rules governing Syntax, Semantics, and Timing.
Effectiveness: Delivery (Right node), Accuracy, Timeliness, Jitter (Delay variance)

5. 3-Tier ISP Architecture & Internet Structure
  • Tier 1 ISPs: Global backbone carriers (AT&T, Lumen, Tata). Own trans-oceanic cables. Zero transit fees; free settlement peering.
  • Tier 2 ISPs: Regional operators (Airtel, Jio). Buy transit from Tier 1; peer at IXPs (Internet Exchange Points).
  • Tier 3 ISPs: Local retail broadband (ACT, Hathway, FTTH). Last-mile access to homes and businesses.
  • POP (Point of Presence): Physical interface facility where external networks hook into an ISP backbone.
6. Protocols, Standards Organizations & Layering Principles
Protocol 3 Elements:
  • Syntax: Data structure & bit field layout.
  • Semantics: Meaning & control actions.
  • Timing: Speed matching & sequencing.
De Jure vs De Facto:
  • De Jure: Legally approved by treaty bodies (ISO 7498, IEEE 802.3).
  • De Facto: Established by industry adoption without formal law (TCP/IP).
Standards Organizations:
  • ISO: OSI Reference Model (7 Layers).
  • IEEE: LAN standards (802.3, 802.11).
  • IETF: Internet Standards via RFCs.
  • ITU-T: Telecommunications sector.
Service Access Points (SAPs): Layer (N-1) offers service to Layer N through SAPs using Primitives: Request, Indication, Response, Confirm.

2. Encapsulation & Trailer T2 Anatomy
  • Encapsulation (Top-to-Bottom): Har layer apna protocol header append karti hai ($H_7 o H_6 o H_5 o H_4 o H_3 o H_2$).
  • Unique DLL Trailer ($T_2$): Data link layer akeli layer hai jo Header ($H_2$) ke sath Trailer ($T_2$) bhi append karti hai.
  • $T_2$ carries CRC Checksum hardware bit-error detection ke liye!
  • Decapsulation (Bottom-to-Top): Receiving host par headers inspect aur strip hote hain.
3. The 3 Distinct Delivery Scopes (AKTU Must-Know)
  • 1. Hop-to-Hop (Data Link Layer): Frame ko ek router/switch se agle adjacent router tak move karta hai using MAC Addresses. MAC changes at every hop!
  • 2. Host-to-Host (Network Layer): Packet ko source host computer se destination host tak deliver karta hai using IP Addresses. IP stays constant end-to-end!
  • 3. Process-to-Process (Transport Layer): Packet ko computer ke exact running application (e.g. Chrome tab) tak deliver karta hai using Port Numbers.

5. 4 Levels of Network Addressing in TCP/IP
  • Physical (MAC) Address: 48-bit (6 Bytes). Hexadecimal format: 00:1A:2B:3C:4D:5E. First 24 bits = OUI (Vendor ID); Last 24 bits = NIC Serial. Burned into hardware.
  • Logical (IP) Address: Universal host identifier across subnets. IPv4 = 32-bit (4 Bytes dotted-decimal 192.168.1.1); IPv6 = 128-bit (16 Bytes hex).
  • Port Address: 16-bit integer (0 to 65,535). Well-known: 0-1023 (HTTP 80, HTTPS 443, DNS 53, SSH 22). Registered: 1024-49151. Dynamic: 49152-65535.
  • Specific / Application Address: User-friendly URLs (www.aktu.ac.in) and emails. DNS resolves URL $ o$ IP.
Socket Address = IP Address : Port Number (e.g. 192.168.1.10 : 8080)

1. Transmission Impairments & Decibels
  • Attenuation: Loss of energy over distance. Solved by Amplifiers/Repeaters.
    dB = 10 log₁₀(P₂ / P₁) | dB = 20 log₁₀(V₂ / V₁)
    Power halved $\implies -3 ext{ dB}$. Multi-stage: $ ext{dB}_{ ext{total}} = ext{dB}_1 + ext{dB}_2$.
  • Distortion: Phase shift in composite signals (frequencies travel at different velocities).
  • Noise: Thermal ($kTB$), Induced, Crosstalk (wire coupling), Impulse (lightning spikes).
    SNR = P_signal / P_noise | SNR_dB = 10 log₁₀(SNR)
2. Nyquist vs Shannon Channel Capacity
  • Nyquist (Noiseless Ideal Channel):
    C = 2 · B · log₂(M) bps | Baud = 2 · B
    $B$ = Bandwidth (Hz), $M$ = Discrete signal voltage levels.
  • Shannon (Noisy Real-World Channel):
    C = B · log₂(1 + SNR) bps (Absolute Physical Ceiling!)
    Linear SNR $= 10^{ ext{SNR}_{ ext{dB}} / 10}$. If $B=3000 ext{ Hz}, ext{SNR}=31.62 ext{ dB} \implies C pprox 31.6 ext{ kbps}$.
  • Synthesis (Find M): $2B \log_2(M) \le C_{ ext{Shannon}} \implies M \le \sqrt{1 + ext{SNR}}$.
3. Network Latency Breakdown (4 Delay Components) & Performance Metrics
  • Transmission Delay: $T_t = rac{L}{B}$ (Packet Length $L$ / Bandwidth $B$). Independent of distance!
  • Propagation Delay: $T_p = rac{d}{v}$ (Distance $d$ / Wave velocity $v pprox 2 imes 10^8 ext{ m/s}$). Independent of packet size!
  • Queuing Delay ($T_q$): Time waiting in intermediate router buffer queues.
  • Processing Delay ($T_{ ext{proc}}$): Header inspection, CRC verify, route lookup.
Total Latency T = Tt + Tp + Tq + Tproc | RTT ≈ 2 · Tp + Tt
BDP (Bandwidth-Delay Product) = Bandwidth · Tp (Bits in Flight)
  • Throughput: Actual measured delivery rate ($\le ext{Bandwidth}$).
  • Goodput: Application payload delivery rate (excludes headers).
  • Jitter: Delay variance between successive arriving packets.

5. Switching Techniques Compared
  • Circuit Switching: Dedicated physical path. 3 Phases (Setup $ o$ Data $ o$ Teardown). Zero queuing delay, but bandwidth wasted during silence. (PSTN Telephone).
  • Message Switching: Entire message stored and forwarded at every node. Huge hard drive buffers required. High delay. (Telegraph).
  • Packet Switching: Small packets (MTU). Statistical multiplexing, concurrent pipelining.
    • Datagram (Connectionless): Packets routed independently; can arrive out-of-order; robust. (IP).
    • Virtual Circuit (Connection-oriented): Pre-planned path (SVC/PVC); in-order arrival; uses VCI. (ATM).
