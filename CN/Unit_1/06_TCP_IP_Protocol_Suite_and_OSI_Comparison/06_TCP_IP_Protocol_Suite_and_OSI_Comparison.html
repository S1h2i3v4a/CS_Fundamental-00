Module 06: TCP/IP Protocol Suite & OSI Comparison

AKTU BCS603 Focus: 4-Layer TCP/IP architecture, protocol stack (IP, ARP, ICMP, TCP, UDP), and authoritative 10-point OSI vs TCP/IP comparison matrix.

1. Core Protocols at Each TCP/IP Layer

  • Application Layer: HTTP/HTTPS (Web), FTP (File transfer), SMTP/IMAP (Email), DNS (Domain name resolution), DHCP (Dynamic IP assignment).
  • Transport Layer:
    • TCP: Connection-oriented, reliable 3-way handshake, checksums, retransmission, flow control (Sliding window), congestion control.
    • UDP: Connectionless, low overhead (8-byte header vs 20-byte TCP header), zero handshake latency, suitable for real-time media.
  • Internet Layer:
    • IP: Best-effort, connectionless packet forwarding across autonomous networks.
    • ARP: Resolves known IP address to unknown 48-bit MAC address via broadcast request and unicast reply.
    • ICMP: Out-of-band network diagnostic signals (Echo Request / Echo Reply for ping).
  • Network Access Layer: IEEE 802.3 Ethernet framing, IEEE 802.11 Wi-Fi frames, physical transceivers.

2. OSI vs TCP/IP Architecture Comparison

Feature OSI Reference Model TCP/IP Model
Model Type Conceptual & Descriptive Functional & Implementation standard
Layer Count 7 Layers 4 Layers (RFC 1122) / 5 Layers
Network Layer Connection-oriented and Connectionless Strictly Connectionless (IP Datagram)
