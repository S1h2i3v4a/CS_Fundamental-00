Module 02: Network Topologies & Design Trade-offs

AKTU BCS603 Focus: Architectural layout, link calculation formulas, fault isolation, and comparative evaluation of Mesh, Star, Bus, Ring, and Hybrid topologies.

1. Mathematical Formulation Summary ($n$ Nodes)

Topology Link Formula Ports per Device Cabling Volume Reliability Profile
Mesh n(n - 1) / 2 n - 1 O(n²) — Maximum Exceptional; Alternate paths exist for every node pair
Star n 1 O(n) — Moderate High node resilience; Vulnerable to Central Hub failure
Bus 1 backbone + n drops 1 tap O(1) trunk — Lowest Low; Backbone cut collapses whole segment
Ring n 2 (In / Out) O(n) — Low Moderate; Single node failure breaks token circulation

2. Star vs Mesh Comparison (Exam Favorite)

  • Mesh Topology: Provides guaranteed bandwidth and zero collision, but cable cost scales as $O(n^2)$. Practically deployed in core backbone networks (ISP Core, Defense).
  • Star Topology: Industry standard for Enterprise LANs (10/100/1000Base-T Ethernet). Cheap twisted pair cables, easy troubleshooting, plug-and-play expansion. Central failure risk is mitigated by using dual redundant Managed Switches.
