2. Bridge Learning & Filtering Algorithm

Bridge incoming frames ke source MAC address se network topology learn karta hai:

Frame Arrives on Port P with [Src: MAC_S, Dst: MAC_D]
1. Update Table: MAC_S -> Port P
2. If MAC_D is in Table:
      If Port(MAC_D) == P: DROP / FILTER Frame (Local traffic)
      Else: FORWARD Frame to Port(MAC_D)
3. Else: FLOOD Frame to all ports except P
