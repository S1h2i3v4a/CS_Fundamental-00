Out-of-Order Buffering & NAK Mechanics

In-depth architectural analysis of Selective Repeat ARQ, receiver reassembly buffer logic, NAK selective rejection, and formal mathematical derivation of window sizing $W_S = W_R = 2^{m-1}$.

1. Selective Repeat vs Go-Back-N

While Go-Back-N discards all subsequent frames upon encountering a gap, Selective Repeat accepts and buffers out-of-order frames ($W_R = 2^{m-1}$). It selectively requests retransmission of only the missing frame via NAK frames.

2. Formal Proof of $W_S = W_R = 2^{m-1}$

Window Boundary Constraint

W_Sender + W_Receiver ≤ 2^m
Since W_S = W_R: 2 · W_S ≤ 2^m → W_S ≤ 2^(m-1)

If $W_S > 2^{m-1}$, duplicate frames from an unacknowledged old window will map directly into the advance receiver window, producing undetectable data corruption.
