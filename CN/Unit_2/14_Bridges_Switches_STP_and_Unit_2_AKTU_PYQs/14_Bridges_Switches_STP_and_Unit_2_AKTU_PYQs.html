2. Spanning Tree Protocol (STP 802.1D)

STP Algorithmic Steps

1. Elect Root Bridge (Lowest Bridge ID = Priority + MAC)
2. Select Root Port on non-root bridges (Lowest path cost to Root)
3. Select Designated Port per segment (Lowest path cost to Root)
4. Place remaining redundant loop-causing ports in BLOCKING state
