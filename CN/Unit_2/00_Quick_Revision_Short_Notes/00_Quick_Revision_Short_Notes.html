1. Data Link Layer (DLL) Foundations & Framing Module 01
  • DLL Core Responsibilities: Framing, Flow Control, Error Control, Physical Addressing (MAC), and Channel Access Control (MAC Sublayer).
  • LLC (802.2) vs MAC: LLC handles upper protocol multiplexing & flow control (medium independent). MAC handles channel access, framing & contention.
  • Framing Methods:
    • Character Count: Frame header carries total byte count. Vulnerable: 1 corrupted count bit desynchronizes all subsequent frames!
    • Byte / Character Stuffing: Flag byte (`0x7E`) delimits frame. If Flag occurs in payload, prefix with `ESC` (`0x1B`). If ESC in payload, prefix with `ESC`.
    • Bit Stuffing (5-Ones Rule): Flag = `01111110`. Sender automatically stuffs a `0` after five consecutive `1`s (`111110`). Receiver unstuffs it.
Bit Stuffing: 011111101111110 -> 011111(0)1011111(0)10
2. Pure ALOHA vs Slotted ALOHA Module 02
  • Pure ALOHA (Continuous): Station transmits immediately whenever data is ready.
    • Vulnerable Time: T_vuln = 2 · T_fr
    • Poisson Throughput: S = G · e^(-2G)
    • Max Throughput: S_max = 1 / (2e) ≈ 18.4% at G = 0.5.
  • Slotted ALOHA (Discrete Clock Slots): Station can only transmit at beginning of slot (Slot duration = T_fr).
    • Vulnerable Time: T_vuln = 1 · T_fr (Halved!)
    • Poisson Throughput: S = G · e^(-G)
    • Max Throughput: S_max = 1 / e ≈ 36.8% at G = 1.0 (Doubled!).
AKTU Poisson: P(k) = (G^k · e^(-G)) / k! | P(0) = e^(-G) (1 slot)
3. Carrier Sense Multiple Access (CSMA) & Persistence Strategies Module 03
1-Persistent CSMA:
  • Continuously senses channel.
  • If Idle: Transmits immediately (p=1).
  • If Busy: Keeps continuous listening.
  • High collision if 2 stations wait for busy channel to free!
Non-Persistent CSMA:
  • Senses channel once.
  • If Idle: Transmits immediately.
  • If Busy: Waits random backoff time before sensing again.
  • Reduces collisions; wastes channel idle time. Peak ~0.8.
p-Persistent CSMA:
  • Used in slotted channels.
  • If Idle: Transmits with prob p; defers to next slot with prob 1 - p.
  • Optimal: N · p < 1 to prevent collisions.
Collision Window: t in [0, Tp] due to propagation delay. Carrier sensing cannot see ahead of wavefront!
4. CSMA with Collision Detection (CSMA/CD) Module 04
  • Mechanism: "Listen While Talk". Transceiver checks voltage: V_chan > 2 · V_tx indicates collision.
  • Collision Action: Immediately abort frame + Broadcast 32/48-bit Jam Signal + Increment k (collision count).
  • Binary Exponential Backoff (BEB): Wait R · Slot_Time where 0 ≤ R ≤ 2^k - 1 (Max k=10; Abort at k=16).
  • Core Derivation (64-Byte Frame):
    T_t ≥ 2 · T_p ==> L_min = 2 · T_p · Bandwidth = 512 bits = 64 Bytes
5. CSMA with Collision Avoidance (CSMA/CA) Module 05
  • Why CSMA/CD Fails in Wireless:
    • Dynamic Range: Transmit power drowns received power (Tx blinds Rx).
    • Hidden Station Problem: A & C cannot hear each other; collide at B.
    • Exposed Station: C refrains from sending to D due to hearing A-B.
  • Interframe Spaces (IFS): SIFS < PIFS < DIFS < EIFS (Shortest IFS = Highest Priority; SIFS for ACK/CTS).
  • 4-Way RTS/CTS Handshake: RTS carries duration; CTS echoes it. Stations overhearing CTS set NAV countdown timer (Virtual Sensing).
NAV = SIFS + T_CTS + SIFS + T_DATA + SIFS + T_ACK

6. Controlled Access & CDMA Channelization Module 06
Controlled Access Methods:
  • Reservation: N bit reservation interval precedes N data frames.
  • Polling: Primary-Secondary architecture. Poll (asks data), Select (sends data). Single point of failure at Primary.
  • Token Passing: Special Token frame circulating in logical ring. Station holding token transmits for Token Holding Time (THT). Zero collisions!
CDMA & Orthogonal Walsh Codes:
  • Walsh Recursive Construction: W_2N = [W_N, W_N; W_N, -W_N]
  • Properties: Wi · Wi = N and Wi · Wj = 0 (i ≠ j)
  • Data Encoding: Bit 0 = -1, Bit 1 = +1, Silent = 0. Transmitted: Si = di · Wi.
  • Channel Signal: C = Σ Si | Receiver Decoding: di = (C · Wi) / N
Example: C = [1, 1, -1, 3], W2 = [1, -1, 1, -1] -> C · W2 = 1 - 1 - 1 - 3 = -4 -> d2 = -4/4 = -1 (Bit 0 Decoded!)
7. Flow Control Foundations & Stop-and-Wait ARQ Protocol Module 07
  • Flow Control: Prevents fast sender from overflowing slow receiver buffer.
  • Error Control (ARQ): Adds Timer + Retransmission + Sequence Numbers.
  • 1-Bit Sequence Numbering (0 & 1): Prevents duplicate frame acceptance when ACK is lost! Receiver ACK n expects frame n.
  • Piggybacking: Outgoing ACK combined inside outgoing data frame header.
Total Time T_total = T_t + 2 · T_p (Neglecting Tack, Tproc)
Parameter a = T_p / T_t = (d / v) / (L / Bandwidth)
Efficiency η = T_t / (T_t + 2 · T_p) = 1 / (1 + 2a) | Throughput = η · B

Physical Impact of 'a': If a >> 1 (Satellite link, a=250): η drops to 1 / (1 + 500) ≈ 0.2%! Motivates Sliding Window Pipelining.

9. Error Detection: Parity, Checksum & CRC Module 10
  • Error Types: Single-Bit vs Burst Error (Length = first to last flipped bit index).
  • Parity: 1D parity fails on even-bit flips. 2D Parity detects all 1, 2, 3-bit errors; corrects 1-bit error via row-column intersection.
  • Internet Checksum: 16-bit 1's complement sum. Wrap-around carry added to LSB. Final result complemented. Receiver sum must be all 1s.
  • Cyclic Redundancy Check (CRC): Modulo-2 XOR division.
    • Degree of G(x) is r. Append r zeros to data.
    • Divide by G(x) using Modulo-2 arithmetic.
    • Remainder R is CRC (FCS). Codeword = Data + R.
    • Receiver checks if Codeword mod G(x) == 0.
CRC-32: Used in 802.3 Ethernet FCS. Detects 100% burst errors ≤ 32 bits!
10. Error Correction & Hamming Code Module 11
  • Hamming Distance (d_min):
    • To detect d errors: d_min ≥ d + 1
    • To correct t errors: d_min ≥ 2t + 1
  • Redundancy Formula: 2^r ≥ m + r + 1 (For m=4 bits data → r=3 bits → Hamming (7, 4) Code).
  • Bit Positions: Parity at powers of 2 (1, 2, 4). Data at 3, 5, 6, 7.
    p1 = d1 ⊕ d2 ⊕ d4 | p2 = d1 ⊕ d3 ⊕ d4 | p4 = d2 ⊕ d3 ⊕ d4
  • Syndrome Word (S4 S2 S1):
    S1 = b1⊕b3⊕b5⊕b7 | S2 = b2⊕b3⊕b6⊕b7 | S4 = b4⊕b5⊕b6⊕b7
    Value of (S4 S2 S1) directly gives the erroneous bit index! Invert to correct.

  • Frame Limits: Minimum = 64 Bytes (512 bits); Maximum = 1518 Bytes.
  • MAC Address (48 bits): First 24 bits = OUI (Vendor ID); Last 24 bits = NIC serial. Broadcast = FF:FF:FF:FF:FF:FF.

12. Token Ring (802.5) & FDDI Module 13
  • IEEE 802.5 Token Ring: Physical star, logical ring via MSAU. Token = SD (1B) + AC (1B) + ED (1B). Active Monitor clears orphan frames & lost tokens. Early Token Release in 16 Mbps.
  • FDDI (100 Mbps Optical Fiber):
    • Dual Counter-Rotating Ring (Primary CW + Secondary CCW).
    • Self-Healing: Cable cut triggers wrap-around into 1 single ring!
    • Timed Token Protocol: THT = max(0, TTRT - TRT).
13. Bridges, Switches & STP (802.1D) Module 14
  • Collision vs Broadcast Domains: Switch splits collision domains (1 per port); preserves 1 broadcast domain.
  • Transparent Bridge Learning: Learn (Source MAC), Forward/Filter (Dest MAC), Flood (Unknown/Broadcast).
  • Spanning Tree Protocol (STP 802.1D): Prevents broadcast storms & loops.
    • 1. Elect Root Bridge (Lowest Bridge ID: Priority + MAC).
    • 2. Select Root Port (RP) per non-root bridge (Lowest path cost).
    • 3. Select Designated Port (DP) per segment.
    • 4. Place redundant ports in BLOCKING state!
