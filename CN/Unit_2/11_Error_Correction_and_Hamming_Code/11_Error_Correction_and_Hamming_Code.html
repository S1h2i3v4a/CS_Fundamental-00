Forward Error Correction (FEC)

Mathematical principles of error correction: Hamming distance theorems, redundancy inequality $2^r \ge m+r+1$, parity placement at powers of 2, and syndrome word error location decoding.

1. Hamming Distance & FEC

Forward Error Correction allows the receiving terminal to detect and automatically correct bit flips without requiring retransmission. A code with minimum distance $d_{min}$ can detect $d$ errors if $d_{min} \ge d + 1$ and correct $t$ errors if $d_{min} \ge 2t + 1$.

2. Hamming (7, 4) Syndrome Decoding

Syndrome Word Error Locator

S1 = b1 ⊕ b3 ⊕ b5 ⊕ b7
S2 = b2 ⊕ b3 ⊕ b6 ⊕ b7
S4 = b4 ⊕ b5 ⊕ b6 ⊕ b7
Syndrome (S4 S2 S1)_2 = Error Bit Index (1 to 7)
