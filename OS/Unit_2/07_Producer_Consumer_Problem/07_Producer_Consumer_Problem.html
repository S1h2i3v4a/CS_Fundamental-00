7. Producer-Consumer (Bounded Buffer) Problem

Syllabus Coverage: Gateway Classes Slides 65–75 | Circular Buffer, Assembly Race Condition, 3 Semaphores Coordination, Deadlock Pitfall.

7.1 Buffer Architecture & Pointers

Circular array of size N. Producer places items at in, Consumer extracts items from out.

7.2 Synchronization Semaphores

  • semaphore mutex = 1; — Ensures mutual exclusion while touching buffer pointers.
  • semaphore empty = N; — Counts available free slots.
  • semaphore full = 0; — Counts items available for consumption.

7.3 The Critical Deadlock Trap

Reversing the wait calls to wait(mutex); wait(empty); results in an immediate Deadlock when the buffer is full, because the Producer holds the lock while sleeping, starving the Consumer from freeing any space.
