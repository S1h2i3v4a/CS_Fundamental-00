8. Classical Problems: Readers-Writers Problem

Syllabus Coverage: Gateway Classes Slides 76–92 | Conflict Matrix, First Readers-Writers Problem, Execution Trace, Writer Starvation.

8.1 Access Rules & Protocols

Readers may read concurrently; Writers require exclusive mutual exclusion.

  • semaphore mutex = 1; — Protects reader counter rc.
  • semaphore db = 1; — Mutual exclusion lock for the database.

8.2 The "First In, Last Out" Semaphore Lock Rule

// First reader locks DB for all readers
if (rc == 1) wait(db);

// Last reader unlocks DB for writers
if (rc == 0) signal(db);

8.3 Starvation Dilemma

If new readers arrive continuously before active readers finish, rc never reaches zero, leading to indefinite starvation of pending writers.
