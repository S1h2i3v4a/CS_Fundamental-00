Module 04: Paging Architecture and Address Translation

AKTU BCS401 Unit 4 Non-Contiguous Memory Paging

1. Fundamental Paging Rules

Physical memory is split into fixed-size Frames; Logical space is split into identical-size Pages. Frame Size = Page Size = 2^n bytes. External fragmentation is completely eliminated!

2. Address Translation Formula

CPU generates (p, d). MMU accesses Page Table at index p to retrieve Frame Number f. Physical Address = (f × FrameSize) + d.

4. Solved Address Translation Numerical

Given: Page Size = 4096 bytes, Page 5 maps to Frame 12.
Logical Address: 20500.
1. Page Number p = floor(20500 / 4096) = 5.
2. Offset d = 20500 mod 4096 = 20.
3. Physical Address = (12 × 4096) + 20 = 49152 + 20 = 49172.
