• Poori list search nahi karni padti Disadvantages: • Shuruati memory blocks me tiny unusable holes jama ho jate hain. Time Complexity: O(n) worst / O(1) best 2. Best Fit Working Principle: Poori list search karo aur wo hole chuno jo process se bada ho aur SMALLEST ho. Advantages: • Badi holes preserve rehti hain future ke bade processes ke liye. Disadvantages: • Generates smallest leftover holes jo kisi kaam ke nahi hote (Worst fragmentation). Time Complexity: Strictly O(n) 3. Worst Fit Working Principle: Poori list me se LARGEST available hole ko choose karo aur allocate karo. Advantages: • Leftover hole ka size bada hota hai, jisme naya process fit ho sakta hai. Disadvantages: • System ke largest holes jaldi khatam ho jate hain; bade jobs starve karte hain. Time Complexity: Strictly O(n) 4. Next Fit & Compact Next Fit Strategy: First Fit ki tarah, lekin search start se nahi balki LAST ALLOCATION pointer se hoti hai. Compaction (Defra): External fragmentation khatam karne ke liye saare processes ko memory ke ek side shift karna taaki ek bada contiguous free block ban jaye. Compaction Condition: Possible ONLY if Dynamic Relocation is supported at runtime!

3. Compaction (Defragmentation)

External fragmentation ko khatam karne ke liye saare processes ko relocate karke contiguous hole banaya jata hai. Iske liye Execution Time Dynamic Relocation mandatory hota hai.
