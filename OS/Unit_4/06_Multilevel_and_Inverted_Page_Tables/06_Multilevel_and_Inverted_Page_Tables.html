Module 06: Multilevel and Inverted Page Tables

AKTU BCS401 Unit 4 Advanced Paging Architectures

1. Page Table Scaling Problem

32-bit system me 4KB pages ke sath har process ko 4MB ka contiguous page table chahiye. Multilevel paging is samasya ko solve karti hai page table ko khud page karke.

2. Two-Level Paging vs Inverted Page Table

ParameterHierarchical (Multilevel) PagingInverted Page Table
Number of TablesHar process ke liye alag multi-level hierarchyPoore system me strictly EK table
IndexingVirtual Page Number ke dwara indexPhysical Frame Number ke dwara index
Memory OverheadHigh virtual space ke sath badhta haiRAM size ke proportional (Extremely small)
Search Overheadk-level me (k+1) RAM accesses per missSlow linear search (Hash table required)

3. Address Breakdown Formula

Two-Level 32-bit: Logical Address = [p1 : 10 bits] | [p2 : 10 bits] | [d : 12 bits]
Inverted Address: Logical Address = <PID, Page Number, Offset> → Matches Frame Index i in table.
