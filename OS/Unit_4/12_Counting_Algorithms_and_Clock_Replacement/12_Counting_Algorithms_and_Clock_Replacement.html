AKTU BCS401 Unit 4 Clock & Counting Replacement

1. Second Chance (Clock) Replacement

Circular queue with a clock pointer. If Reference bit R=0 → Replace. If R=1 → Clear R=0, give second chance, advance pointer.

2. Enhanced Second Chance 4-Class Model

Class <R, M>MeaningAction
(0, 0)Not recently used, Clean (not modified)Best candidate for replacement
(0, 1)Not recently used, Dirty (modified)Requires disk write before page-out
(1, 0)Recently used, CleanLikely in active working set
(1, 1)Recently used, DirtyWorst candidate

3. LFU vs MFU

• LFU: Smallest reference count replaced.
• MFU: Highest reference count replaced (protects new arrivals).
