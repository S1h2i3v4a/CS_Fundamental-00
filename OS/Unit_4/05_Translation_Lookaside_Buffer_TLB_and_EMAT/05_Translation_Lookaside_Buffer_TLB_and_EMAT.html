1. Pure Paging Overhead Problem

Pure paging me har instruction aur data access ke liye do memory references lagte hain: Page table lookup (100ns) + Data access (100ns) = 200ns. Is 100% latency penalty ko door karne ke liye CPU me TLB (Translation Lookaside Buffer) hardware cache add hota hai.

3. Protection & Valid-Invalid Bits

• Valid (1): Page process ke valid address space me map hai.
• Invalid (0): Illegal address access (Hardware trap / Segmentation Fault).
• Permission bits: Read (r), Write (w), Execute (x) enforce protection.
