1. SMP, Processor Affinity & NUMA Architecture

2. Key Concepts Summary

ConceptDefinition & Role
Asymmetric (AMP)Master CPU handles OS/IO; Slaves run user code only.
Symmetric (SMP)All CPUs are peers; self-scheduling.
Processor AffinityProcess prefers to run on same CPU to exploit warm L1/L2 cache.
Push MigrationPeriodic task redistributes load from overloaded to idle cores.
Pull MigrationIdle core pulls waiting tasks from busy core run-queues.
