1. Process Concept: Program vs Process

Program (Passive): Disk par stored static machine binary code file hai.
Process (Active): Program in execution. Iske paas memory address space, allocated CPU registers, stack, aur heap hota hai.

Process Address Space Layout

Memory SegmentDescriptionGrowth Direction
StackLocal variables, function return addresses, parametersHigh to Low Memory (Downwards)
HeapDynamic runtime allocation (malloc, calloc, new)Low to High Memory (Upwards)
DataGlobal and static variables (Initialized .data and Uninitialized .bss)Fixed at launch
TextCompiled read-only executable instructionsFixed

2. Process State Transition Model

Key Transition Rules:
1. New → Ready: Long-Term Scheduler (LTS) dwara admission.
2. Ready → Running: Short-Term Scheduler (STS) / Dispatcher allocation.
3. Running → Ready: Timer interrupt (Preemption) ya higher priority process arrival.
4. Running → Waiting: I/O request ya event wait system call.
5. Waiting → Ready: I/O completion interrupt (Directly running nahi ja sakta!).
