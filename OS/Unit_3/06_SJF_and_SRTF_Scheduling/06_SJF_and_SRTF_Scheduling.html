2. Exponential Smoothing Burst Prediction

$$\tau_{n+1} = \alpha t_n + (1 - \alpha) \tau_n$$
  • t_n: Actual length of n-th CPU burst
  • τ_n: Predicted length of n-th CPU burst
  • α: Smoothing weight factor (0 ≤ α ≤ 1)
