1. Concept & Access Matrix Model

Protection ensures unauthorized processes cannot perform prohibited operations (Read, Write, Execute, Delete) on files. The theoretical Access Matrix represents rights as a 2D table of Domains (Rows) × Objects (Columns).

2. Implementation: ACL vs Capability Lists

Metric Access Control List (ACL) Capability List (C-List)
Matrix Slice Column Slices (Attached to File) Row Slices (Attached to Process/Domain)
Revocation Very Easy (Delete user from file's ACL) Hard (Must trace and invalidate distributed tokens)
Access Check Search ACL for matching user ID O(1) Instant (Process presents capability ticket)
Adoption Windows NTFS, POSIX ACLs Microkernels (seL4, Fuchsia)

3. UNIX 9-Bit Protection Scheme (chmod)

UNIX simplifies matrix storage into 9 bits: 3 bits each for User (Owner), Group, and Others.

Permissions: r = 4, w = 2, x = 1
chmod 754: Owner = 4+2+1 (7), Group = 4+0+1 (5), Others = 4+0+0 (4)
Terminal output: -rwxr-xr--
Special Bits (12-bit mode):
• SUID (4000): File executes with owner's privilege (e.g. passwd binary).
• SGID (2000): File executes with group privileges.
• Sticky Bit (1000): Used in /tmp (1777); only file creator can delete their file.
