Module 03: SQL Foundations, Data Types, and DDL Commands

DDL Auto-Commit: DDL commands (CREATE, ALTER, DROP, TRUNCATE) modify the data dictionary directly and are automatically committed!

1. Essential SQL Data Types

TypeStorageDescription
CHAR(n)Fixed n bytesFixed length string padded with trailing spaces. Ideal for fixed-width identifiers.
VARCHAR(n)Variable lengthDynamic string up to n characters. Space-efficient for names and descriptions.
DECIMAL(p, s)Exact precisionFixed-point numeric with p total digits and s fractional digits (e.g. monetary amounts).
TIMESTAMPDate + TimeCalendar date, hour, minute, second, and fractional microsecond values.
