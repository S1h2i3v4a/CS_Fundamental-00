Module 05: SQL Clauses, Aggregate Functions, and Groupings

Execution Pipeline: The physical database engine executes FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY.

1. WHERE vs HAVING Comparison

FeatureWHEREHAVING
ScopeIndividual rows before grouping.Grouped summary buckets after aggregation.
AggregatesForbidden (e.g. WHERE AVG(x) is invalid).Allowed (e.g. HAVING COUNT(*) > 5).
TimingFilters input tuples early.Filters groups late in pipeline.

2. Aggregate Functions

All aggregate functions (SUM, AVG, MIN, MAX, COUNT(col)) strictly ignore NULL entries. Only COUNT(*) counts all rows including NULL records.
