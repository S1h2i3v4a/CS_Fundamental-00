CASCADE: Deleting/updating parent auto-deletes/updates child rows. 2. SET NULL: Deleting parent sets foreign key in child to NULL. 3. SET DEFAULT: Deleting parent resets child FK to its default value. 4. RESTRICT / NO ACTION: Rejects parent deletion if child row exists! Default action in SQL is RESTRICT (prevents orphaned records).
Data Manipulation & Integrity: DML commands operate on data rows, while integrity constraints guarantee ACID database consistency.

2. Referential Integrity Actions

When a parent key is deleted or updated: CASCADE propagates changes, SET NULL blanks child foreign keys, and RESTRICT rejects parent deletion to prevent orphaned records.
