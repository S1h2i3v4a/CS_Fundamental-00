Module 09: Database Indexes and Access Paths

Indexing Trade-off: Indexes drastically accelerate SELECT query retrieval from O(N) to O(log N), but add overhead to INSERT/UPDATE/DELETE statements due to index tree maintenance.

1. Clustered vs Non-Clustered Index

FeatureClustered IndexNon-Clustered Index
Physical SortPhysically sorts table data on disk.Independent B-Tree pointing to data rows.
Count LimitExactly 1 per table.Multiple allowed per table.
Leaf NodesActual data rows.Search keys + Row Pointers.

2. Sparse Indexing Rule

A Sparse Index stores block anchors (1 entry per block). It is compact enough to fit in RAM, but strictly requires the underlying data file to be sorted.
