## 🎯 High-Yield AKTU Exam Highlights

1. **Serializability Verification (Every year 10 Marks):**
   - Step 1: Draw Precedence Graph for schedule $S$.
   - Step 2: Check for directed cycles. No cycle $\implies$ Schedule is **Conflict Serializable**.
   - Step 3: If cycle exists, check for **Blind Writes** ($W(Q)$ without prior $R(Q)$). If no blind writes exist, schedule is definitely **NOT View Serializable**.
2. **Recoverability Hierarchy:**
   $$	ext{Strict Schedules} \subset 	ext{Cascadeless (ACA)} \subset 	ext{Recoverable} \subset 	ext{All Schedules}$$
   - *Cascadeless condition:* $Commit(T_i) < Read_j(X)$.
   - *Strict condition:* $Commit/Abort(T_i) < Read_j(X) 	ext{ and } Write_j(X)$.
3. **Deadlock Timestamp Schemes:**
   - **Wait-Die (Non-preemptive):** Older transaction waits; Younger dies.
   - **Wound-Wait (Preemptive):** Older transaction wounds/preempts Younger; Younger waits. Starvation-free!
4. **Log-Based Recovery (WAL):**
   - Log record must reach stable storage **before** disk block is written.
   - Deferred modification requires only **REDO** (no undo).
   - Immediate modification requires both **UNDO** and **REDO**.
