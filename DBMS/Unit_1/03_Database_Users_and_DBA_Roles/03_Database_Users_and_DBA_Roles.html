3. Core DBA Responsibilities

1. Schema Definition: Formulates DDL schemas, constraints, and data types.
2. Physical Storage Optimization: Manages B+ Tree indexes, partitioning, and buffer pool sizing.
3. Security & Authorization: Executes GRANT / REVOKE access matrices.
4. Disaster Recovery: Automated backup scheduling and point-in-time crash recovery via WAL logs.
5. Performance Tuning: Diagnoses query bottlenecks and minimizes physical disk I/O.
