Unit 1: Introduction AKTU BCS501 3-Schema Architecture

1. Three-Schema Architecture & Data Abstraction

ANSI/SPARC model decouples user applications from physical storage through three distinct abstraction boundaries: External Level (User Views), Conceptual Level (Logical Schema), and Internal Level (Physical Storage Layout).

2. Physical vs Logical Data Independence

Physical Data Independence: Ability to change internal schema (e.g., adding B+ tree indexes, changing disk partitioning, migrating to NVMe SSD) without modifying conceptual schema or existing application queries.
Logical Data Independence: Ability to modify conceptual schema (e.g., adding new entities or attributes) without altering existing external views or breaking existing application programs.
