2. The 4 Fundamental Integrity Constraints

3. Referential Action Triggers

• CASCADE: Auto-deletes child rows upon parent deletion.
• SET NULL: Sets child FK column to NULL.
• RESTRICT: Rejects parent modification if referenced by active child tuples.
