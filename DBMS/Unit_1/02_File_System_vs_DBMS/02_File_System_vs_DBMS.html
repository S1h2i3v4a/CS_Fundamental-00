2. Core Limitations of Traditional File Systems

  • Data Redundancy & Inconsistency: Duplicate data across departmental files creates out-of-sync states upon update.
  • Data Isolation: Data scattered across heterogeneous file formats (CSV, binary, text).
  • Integrity Problems: Constraints hardcoded inside application programs instead of centralized catalog.
  • Atomicity Failure: Crashes midway during multi-step operations leave files corrupted without rollback.
  • Concurrency Anomalies: Uncoordinated simultaneous writes cause Lost Updates and Dirty Reads.
